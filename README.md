# Black Hole — Gravity Jump

A lightweight retro space puzzle game. Reach the black hole in as few jumps as possible. Planets bend your trajectory — each jump is movement and gravity strategy.

## Play

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (default `http://localhost:5173`).

## Controls

- **Drag** from the ship to aim; release to jump
- **R** — restart level
- **N** — next level
- **Space** — jump (when aiming) / continue (after win/loss)

## Build

```bash
npm run build
npm run preview
```
